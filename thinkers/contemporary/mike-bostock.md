# Mike Bostock (~1982--present)
> "D3 is not a charting library. It is a library for creating visualizations from first principles."

## Overview

Mike Bostock is the creator of D3.js (Data-Driven Documents), the most powerful and flexible JavaScript library for creating web-based interactive visualizations, and co-creator of Observable, the computational notebook platform for visualization publishing. Active from the 2000s to the present, Bostock has fundamentally shaped how visualizations are built and experienced on the web.

As a graphics editor at the *New York Times*, Bostock worked alongside [Amanda Cox](./amanda-cox.md) on some of the most celebrated data journalism pieces in history. His technical vision -- that visualizations should be data-driven, using the full expressive power of web standards -- enabled an explosion of creative interactive visualization across journalism, research, and art.

## Key Contributions

- Created **D3.js** (2011--present), the most widely used JavaScript library for data-driven document manipulation and visualization
- Co-created **Protovis** (2009, with [Jeffrey Heer](./jeffrey-heer.md) and Vadim Ogievetsky), the predecessor to D3
- Co-founded **Observable** (2017--present), a computational notebook platform designed for visualization publishing and exploration
- Served as graphics editor at the *New York Times*, producing landmark interactive data journalism
- Created **Observable Plot**, a higher-level visualization library built on D3 concepts

## Major Works

## Core Philosophy

Bostock believes that visualization on the web should be *data-driven* -- meaning that the visual representation should be a direct function of data, and that when data changes, the visualization updates accordingly. D3 gives practitioners access to the full power of the browser's SVG and canvas capabilities, without imposing a fixed set of chart forms.

D3 is intentionally low-level -- a library for building visualization systems, not an off-the-shelf charting tool. This philosophy prioritizes expressiveness and flexibility over convenience, enabling practitioners to create any visual form they can imagine rather than selecting from a predetermined menu.

With Observable, Bostock extended this vision to the authoring experience itself, creating a platform where computational notebooks are first-class citizens for visualization publishing -- where code, data, and visual output live together in a reactive, shareable environment.

## Influence

D3.js is the engine behind most sophisticated web-based visualizations -- from the NYT's election graphics to Nadieh Bremer's and Shirley Wu's data art. It is the foundational technology for an entire ecosystem of higher-level tools and libraries.

Many other libraries (Vega, Vega-Lite, Observable Plot) are built on top of D3 concepts, forming a layered ecosystem where D3 provides the low-level primitives and higher-level tools provide more accessible APIs for common tasks.

The *New York Times* graphics department, powered by D3 and the team Bostock helped build, defined what data journalism could be in the digital age. Pieces like "512 Paths to the White House" became watershed moments in interactive journalism and set a standard that every serious news organization now aspires to match.

Observable represents Bostock's latest contribution: a rethinking of how visualization work is authored, shared, and published -- making computational notebooks a native medium for data communication.
