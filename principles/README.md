# Principles of Data Visualization

A curated collection of foundational principles that guide effective data visualization design. These principles draw from decades of research across statistics, perceptual psychology, cartography, and human-computer interaction.

## Index

| # | Principle | Description |
|---|-----------|-------------|
| 1 | [Data-Ink Ratio](data-ink-ratio.md) | Maximize the share of ink devoted to data; erase non-data elements that do not inform. |
| 2 | [Chartjunk](chartjunk.md) | Identify and eliminate decorative clutter that obscures, competes with, or replaces data. |
| 3 | [Small Multiples](small-multiples.md) | Use repeated, identically scaled panels to enable direct visual comparison across categories or time. |
| 4 | [Sparklines](sparklines.md) | Embed word-sized, high-resolution graphics inline with text and tables for contextual data display. |
| 5 | [Micro/Macro Readings](micro-macro-readings.md) | Design displays that reveal both individual data points and aggregate patterns within a single view. |
| 6 | [Layering and Separation](layering-and-separation.md) | Use visual stratification to place data in the foreground and structural elements in the background. |
| 7 | [Smallest Effective Difference](smallest-effective-difference.md) | Use the minimum visual distinction that reliably conveys a difference -- no more. |
| 8 | [Lie Factor](lie-factor.md) | Ensure the visual representation of data change matches the actual magnitude of the data change. |
| 9 | [Pre-Attentive Processing](pre-attentive-processing.md) | Leverage the visual features the eye detects instantly to direct attention to the most important data. |
| 10 | [Gestalt Principles](gestalt-principles.md) | Apply the brain's innate grouping rules -- proximity, similarity, enclosure, continuity -- to organize visual information. |
| 11 | [Color Theory](color-theory.md) | Choose color palettes systematically based on data type, perceptual science, and accessibility constraints. |
| 12 | [Grammar of Graphics](grammar-of-graphics.md) | Decompose any chart into orthogonal components -- data, aesthetics, geometry, scales, coordinates -- rather than choosing from a fixed chart-type menu. |
| 13 | [Perceptual Hierarchy](perceptual-hierarchy.md) | Encode the most important variables using the visual channels humans decode most accurately (position > length > angle > area > color). |
| 14 | [Interaction Design](interaction-design.md) | Structure interactive exploration as overview first, zoom and filter, then details on demand. |
| 15 | [Accessibility](accessibility.md) | Design visualizations so that all users, regardless of ability, can access and understand the data. |
| 16 | [Analytical Design](analytical-design.md) | Design displays that assist analytical thinking: comparisons, causality, multivariate data, integrated evidence, and documentation. |

## How to Use This Collection

Each principle file follows a consistent structure:

- **Definition** -- What the principle states and where it originated.
- **Origin** -- The thinker(s), book(s), and year(s) behind the idea.
- **Detailed Explanation** -- Full treatment drawn from primary sources.
- **Examples** -- Good and bad applications.
- **Practical Application** -- Guidelines for practitioners.
- **Common Mistakes** -- What people get wrong.
- **Related Principles** -- Cross-links to complementary ideas in this collection.
- **Key Quotes** -- Notable quotations with attribution.
- **Further Reading** -- Links to thinker profiles and source texts.

## Lineage

These principles span multiple intellectual traditions:

- **Minimalist / Tuftean school**: Data-Ink Ratio, Chartjunk, Small Multiples, Sparklines, Micro/Macro Readings, Layering and Separation, Smallest Effective Difference, Lie Factor, Analytical Design
- **Scientific / Perceptual school**: Pre-Attentive Processing, Gestalt Principles, Perceptual Hierarchy
- **Grammar of Graphics school**: Grammar of Graphics
- **Applied and cross-cutting**: Color Theory, Interaction Design, Accessibility
